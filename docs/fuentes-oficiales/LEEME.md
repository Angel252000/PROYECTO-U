# 📂 Fuentes oficiales del modelo SINAES

Coloca **aquí** los archivos oficiales del Modelo de Grado 2025 que vas a
compartir. De estos archivos extraeré los datos REALES (las 59 pautas, las
dimensiones, los cuestionarios por población, etc.) para reemplazar los
datos de ejemplo.

## Archivos que necesito (los que mencionaste)

| Archivo | Para qué lo uso |
|---|---|
| **Formato 1 — Plantilla Informe autoevaluación (Grado).xlsx** | Extraer las **59 pautas**, dimensiones, categorías (A–D) y fuentes Tipo I–IV |
| **Cuestionario según población.xlsx** | Generar los **cuestionarios** reales por rol (estudiantes, graduados, empleadores, académicos, administrativos) |
| **Formato 2 — Informe preliminar de Pares Evaluadores.xlsx** | Estructurar el módulo de **evaluación externa** |
| **Formato 8 — Compromiso de Mejora e Informe de Logros.xlsx** | Estructurar el **plan de mejora** y su seguimiento |
| **Guía Metodológica para la aplicación de cuestionarios.pdf** | Reglas de aplicación de encuestas |

## Cómo dejarlos

1. Descarga los archivos desde tu correo (Outlook).
2. Cópialos dentro de esta carpeta: `docs/fuentes-oficiales/`.
3. Avísame y los analizo para cargar los datos reales.

> Nota: estos archivos son material de trabajo interno. Si contienen datos
> sensibles, podemos mantenerlos fuera del control de versiones (añadir la
> carpeta a `.gitignore`). Pregúntame y lo configuramos.
